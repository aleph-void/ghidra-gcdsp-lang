# GCDSP p-code cases.  Expectations are worked out by hand from the GameCube DSP User's Manual
# (Duddie, v0.1.8): the operation pseudo-code, the flag rules of the "Flags" section and the opcode
# table.  Registers and flags start at 0, memory at 0; code is placed at inst:0x1000.
# Flags: C carry, O overflow, Z arithmetic zero, S sign, AS above s32, TB top two bits equal,
# LZ logic zero, OS sticky overflow, AM $sr.AM, SXM $sr.SXM (40-bit mode).

# ---------------- accumulator arithmetic and flags ----------------
case add_basic
code 4c00
set acc0 0x10
set acc1 0x20
expect acc0 0x30
expect C 0
expect O 0
expect Z 0
expect S 0
expect AS 0
expect TB 1
end
